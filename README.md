# 复旦研究生选课定时刷新助手

一个 Manifest V3 Chrome 扩展，用于在复旦大学研究生选课页面设置单次定时刷新，并按用户填写的条件定位课程。

> 非复旦大学官方项目。本项目仅供个人学习和辅助操作。使用者应自行遵守学校选课规则与网站使用条款。本扩展不绕过验证码、登录验证、访问频率限制或其他安全机制，也不保证选课成功。

## 功能

- 在指定时间刷新一次选课页面
- 在课程大类与页面内课程类型之间切换
- 按课程名称或代码、星期、节次和校区筛选
- 对第一条符合条件且显示“未满”的课程执行一次点选，并自动完成选课确认
- 自定义 1–300 秒测试延迟
- 记录最近一次点选课程
- 在“已选课程”中按完整课程代码定位并点击退选；最终确认由用户手动完成
- 在插件面板中显示执行阶段和失败原因

当前版本：**v2.2.4**。支持 `yjsxk.fudan.edu.cn` 和 `yjsxk.fudan.sh.cn` 两个选课域名；统一兼容新版 Chrome 对菜单、选课和退选按钮中 `javascript:` 导航的内容安全策略限制。选课自动确认，退选的最终确认由用户手动完成。

## 安装

1. 下载本仓库源码并解压。
2. 在 Chrome 地址栏打开 `chrome://extensions`。
3. 打开右上角“开发者模式”。
4. 点击“加载已解压的扩展程序”。
5. 选择包含 `manifest.json` 的 `fudan-course-refresh` 文件夹。

## 使用

1. 登录复旦研究生选课系统并保持选课标签页打开。
2. 打开扩展面板，选择课程大类和页面内课程类型。
3. 填写足够独特的课程名片段，或优先填写课程代码。
4. 根据需要填写星期、节次和校区；这些附加条件可以留空。
5. 设置执行时间并启动。测试时可以填写延迟秒数并点击测试按钮。
6. 执行后请在“已选课程”页面核对实际结果。

## 隐私与安全

- 扩展不收集、上传或共享用户数据。
- 设置和最近一次课程记录仅保存在 Chrome 本地扩展存储中。
- 源码与发布包不得包含学号、姓名、Cookie、会话信息或选课记录。
- 扩展仅执行单次刷新和单次课程操作，不进行高频循环请求。
